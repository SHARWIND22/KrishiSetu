# Fair Price Index (FPI)

Formula: `FPI = asking price / reference market price`.

Example: ₹46,000 / ₹46,200 = 0.996, approximately 0.43% below the reference.

Thresholds in this demo: below 0.90 = below market; 0.90–1.10 = fair range; above 1.10 = above market. These are configurable demo thresholds, not a validated recommendation. Production data should match commodity, grade, unit, market and date. Always show the data source and freshness.

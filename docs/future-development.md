# Future Development Roadmap

1. **Prototype:** listings, filters, demo FPI, browser-local offer interaction.
2. **Shared marketplace:** backend API, database, verified accounts, cross-device data and offer state management.
3. **Price intelligence:** authorized Agmarknet/data.gov.in integration, dated price snapshots and safe fallback behavior.
4. **Field pilot:** Kannada localization, low-connectivity testing, farmer-group feedback and measurement of listing completion and buyer responses.

Risks to resolve: relevant commodity/grade/unit/market/date matching, privacy, dispute handling and avoiding claims of live data before integration.
